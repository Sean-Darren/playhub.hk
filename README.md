# PlayHub

In-memory Java model of a sports community platform: court booking, community sessions, observer notifications, wallet top-up, and payments.

## Requirements

- JDK 25 (LTS) or later
- Apache Maven 3.9+

## Build and test

```bash
mvn test
```

## Run the demo

```bash
mvn -q exec:java
```

## Layout

| Path | Contents |
|------|----------|
| `code/` | Production sources (`package playhub`) |
| `test/` | JUnit 5 tests |
| `diagram/` | Visual Paradigm design diagram (software design) |
